# 任务：代码库卫生清理

请执行以下检查，对每个发现的问题生成独立的修复 commit：

## 检查清单

1. **超长文件**：找出 `src/paper_trading/` 下超过 400 行的 `.py` 文件，拆分为更小的模块
2. **缺失测试**：找出 `src/paper_trading/` 下没有对应 `test_*.py` 的模块，补充基础测试
3. **未使用的 import**：清理所有未使用的 import 语句（`ruff check --select F401`）
4. **TODO/FIXME**：列出所有 TODO 和 FIXME，超过 30 天未处理则生成清理 commit
5. **重复代码**：找出高度相似的代码段（>10 行），提取为共享工具函数放入 `utils.py`
6. **过时文档**：检查 `docs/` 中超过 60 天未更新的文档，确认是否仍然有效
7. **Ruff 历史告警**：清理 `ruff check .` 中累积的非阻塞告警
8. **硬编码常量**：检查是否有 API 密钥、URL、魔法数字未通过 `settings` 管理

## 约束

- 每个修复作为独立 commit，不要混在一起
- 每个 commit 修改后必须确保 `ruff check . && mypy src/ && pytest` 通过
- Commit 标题格式：`chore(cleanup): [具体描述]`
- 不允许升级 `pyproject.toml` 中锁定的依赖主版本
- 不允许引入新的第三方依赖，优先使用标准库或已有依赖
- 如果不确定某个修改是否安全，跳过并在 commit body 中标注原因
